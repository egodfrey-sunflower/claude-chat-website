# claude-chat-website

Web pages Claude makes during chats, published with GitHub Pages so they're easy to open on a phone.

Live at <https://egodfrey-sunflower.github.io/claude-chat-website/>.

Pages are organised by date: `YYYYMM/DD/<page-name>.html`, with any assets in `YYYYMM/DD/<page-name>/`. See `CLAUDE.md` for the rules.
